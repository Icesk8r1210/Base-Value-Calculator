## Overview

The **Base Value Calculator** lets figure skaters build a program and see its
total base value right away. Choose your jumps, spins, step sequences, program
type, and level, and the app computes the total using **official scoring rules**.

## Features

- Select the **program type**: Short Program or Freeskate
- Select the **level**, from Juvenile through Senior
- Add elements to your program:
  - Jumps
  - Spins
  - Step sequences
  - Choreographic elements
- Calculate the total base value instantly
- Intuitive, user-friendly interface

## Installation

No build tools or dependencies are needed. To run the app locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/Icesk8r1210/Base-Value-Calculator.git
   ```

2. **Move into the project folder**

   ```bash
   cd Base-Value-Calculator
   ```

3. **Open the app** by double-clicking `index.html`, or opening it in your browser.

### Requirements

- A modern web browser (Chrome, Firefox, Safari, or Edge)

## Usage

1. Choose your **program type** (Short or Freeskate).
2. Choose your **level** (Juvenile → Senior).
3. Add your **jumps**, **spins**, **step sequence**, and **choreographic element**.
4. Review the **total base value** shown by the calculator.
5. Adjust your elements to see how the score changes.

> **Tip:** Try different element combinations to plan the highest-scoring program for your level.
